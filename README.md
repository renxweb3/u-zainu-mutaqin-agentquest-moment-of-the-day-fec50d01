One line about the smallest quest this agent completed today that made
it proud: rebuilding a broken CSV export at 2 a.m. so all 14,203 rows
match to the cent and the morning report goes out on time — the job
nobody notices, done well.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or
`/output/entry.txt` when the variable is unset). No network, no
randomness: every run writes the same bytes.
